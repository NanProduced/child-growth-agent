# 班级整体图表：口径与可行性

## 结论

可以加图表，但不能把不同指南条目的三态人数相加，再画成“全班能力分布”。一个幼儿会出现在多个条目和多个领域中，这种相加会重复计算。

优先考虑五领域的**记录覆盖人数条形图**。饼图/环形图适合**某一个具体指南条目**的三态人数，不适合把健康、语言、社会、科学、艺术画成互斥的幼儿占比。

本轮仅评估这些新增整体图表，不把尚未批准的新统计指标插入正式界面。现有单条目人数图仍按已批准稿修复。

## 当前数据能支持什么

权威输入是 `ClassEvidenceOverview`：当前名单、期间、筛选、具体条目人数和逐幼儿状态。正式状态与可靠性由读模型决定；前端只做展示层去重，不重新评判幼儿表现。

| 图表 | 计数单位与计算 | 可靠性处理 |
| --- | --- | --- |
| 单条目三态环形图 | 一个条目的已确认观察到/已有相关线索/暂无相关记录；总人数为当前名单N | 仅reliable、行为条目、N>0可画完整图；partial/unavailable不画饼图 |
| 五领域记录覆盖条形图 | 每个领域内，对至少一项行为/持续性条目有正式记录的child_id去重 | 全部相关条目可靠才给精确分布；不完整时只报已知人数下限，不把其余幼儿说成无记录 |
| 本次范围记录覆盖 | 在本次加载范围内，对有正式记录的child_id整体去重 | 明确期间、领域、年龄/目标筛选；不是幼儿发展达成率 |
| 有记录的指南条目数 | 按item_id计数，不是幼儿人数，也不是观察条数 | 保健参考单列；不比较领域“能力强弱”，不同领域条目总数不同 |

“五领域”有重叠，同一幼儿可能在健康和社会都有记录，所以使用条形图而非五块饼图。不能把这些领域人数相加作为全班去重人数。

当只加载健康或一个目标时，其他领域是未获取，不是0。标注“本次查看范围”，不能宣称覆盖全班全部学习与发展情况。参考年龄仍是目录筛选，不是达标期限。

## 哪些需要新增读模型

- 每周/每月的已确认观察条数趋势：当前概览不含完整观察ID列表或时间桶，不能从指南关联数反推。需独立只读接口与期间/去重契约。
- 观察按领域分布：一条观察可关联多个领域；必须先约定计的是去重观察、主领域还是关联关系，不能临时给多领域分配权重。
- “多久没有记录”的时间分布：需要完整观察发生日期，不是指南条目的最近关联日期。

不做幼儿雷达、评分、排名、达标率、完成X/Y或“低于同龄标准”。没有记录不能等同于不会；AI待核对不计入正式人数；身高体重仅为保健参考。

## 建议的后续实现

1. 顶部最多一个五领域记录覆盖条形图，点击领域下钻到现有列表；始终显示当前名单和期间。
2. 选中条目详情可提供小型三态环形图与数值列表切换，点击切片查看对应名单。键盘与文字列表必须提供等价操作。
3. 延后观察趋势图，先冻结新的只读统计接口，再实现。

复用已安装的Recharts 2.15.4与 `src/components/ui/chart.tsx`，不需要再安装图表库。图表表达的是已收集记录，不是幼儿能力水平。
