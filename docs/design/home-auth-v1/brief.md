## 2. 三态与主行动（对齐 `HOME_PRIMARY_ACTION_CODES`）

| 状态 | 结构 | 主行动（固定优先级） | 边界 |
|---|---|---|---|
| 未登录 | 定位与主标题 → 内嵌登录面板 → 机制三步 | `login` 园所账号登录 | 隐藏业务导航；不加载任何园所数据 |
| 教师 | 身份与负责范围 → 唯一主行动 → 我的班级 → 少量摘要 | `process_confirmations` 去处理待确认 → `supplement_observation` 待补充 → `organize_draft` 待整理 → `create_profile` 建档 / `start_observation` 新记录 | 只显示当前任教范围；三类待办分开计数 |
| 管理员 | 管理身份 → 克制的全园概览 → 管理班级/管理教师入口 | `manage_school` 管理全园（入口映射为管理班级/管理教师） | `pending` 为空、待办计数为 0；不含观察原文、教师名单、图表 |

教师未分配：`await_class_assignment`（等待分配，只引导联系管理员）；读取失败：`retry`；身份不可用：fail closed + 重试。

## 4. 未登录态

- **定位与主标题**：小标签（无衬线）+ 固定主标题（唯一毛笔展示字，可两行）+ 辅助语（无衬线）。
- **内嵌登录面板**：标题“园所账号登录”；账号、密码两个字段；芽叶绿登录按钮；帮助语“账号由园所管理员分配，角色由账号决定”。**无角色选择器、无注册、无任意切换**。错误提示预留位置，不推挤布局。
- **机制三步**：记录原始观察 → AI 整理草稿 → 教师确认归档；弱化一行，无卡片、无数字。
- **顶栏**：仅品牌与“园所账号登录”；**隐藏全部业务导航**（班级/成长档案/观察记录/更多）。
- **插画**：桌面右侧独立列，完整显示，尺寸约 480–520px 宽，不与登录面板重叠。
- **禁止**：儿童数据、班级人数、观察内容、管理入口、任何园所私有数据。

## 5. 教师态

- **身份与负责范围**：真实姓名（无衬线）+ “教师 · 负责 3 个班级 · 54 名幼儿 · 2026–2027 学年”。范围来自服务端会话与任教关系；姓名 1–2 行自适应。
- **示例班级（固定，三班自洽）**：
  - 小班（2 个班级）：芽芽班 18 名幼儿（待确认 2 · 待补充 1 · 待整理 1）；苗苗班 16 名幼儿（待确认 1 · 待整理 2）。
  - 中班（1 个班级）：星星班 20 名幼儿（待补充 1 · 待整理 1）。
  - 合计：18+16+20＝54 名幼儿；待确认 3、待补充 2、待整理 4。
- **唯一主行动**：按固定优先级取第一个非零类别；本示例为“去处理待确认”（琥珀 `#BF6805`）＋“3 条待确认”。**已知低优先级待办仍可处理**：“待补充 2 · 待整理 4”以文字链路呈现，可直接进入；不允许并列多个主按钮。
- **三类待办分开**：待确认（`ai_organized`）、待补充（`needs_input`）、待整理（`draft`）分别计数与展示；**不把观察待确认与指南“AI 关联待核对”混成一个数量**——后者是 G5 工作流状态，不在首页计数、不进入本设计任何数字。
- **我的班级**：学段是分组，组内允许多个班级（示例：小班 2 个班）；每行给出班级名、人数与三类状态中的非零值，0 不渲染成标签。
- **少量摘要**：待办摘录 3 行（每类 1 行，带类别词，可直接进入）；最近观察 2 行（状态“已确认归档”）。长姓名示例“阿依努尔·麦麦提”。
- **未分配班级**：整区替换为“等待班级分配 / 请联系园所管理员安排任教班级。”`await_class_assignment`，**不提供自行创建班级捷径**。
- **已分配无幼儿**：主行动 `create_profile` 建立第一个成长档案；不是错误态。
- **禁止**：全园教师名单、其他班级细节、百分比、排名、驾驶舱指标。

## 6. 管理员态

- **管理身份**：姓名（无衬线）＋“管理员”；范围一句话“示范幼儿园 · 3 个学段 · 6 个班级 · 94 名幼儿”。
- **克制全园概览**：三个学段块，仅显示“班级数 · 幼儿数”：
  - 小班 2 个班级 · 34 名幼儿；中班 2 个班级 · 32 名幼儿；大班 2 个班级 · 28 名幼儿。
  - 学段色只作识别（珊瑚 `#A7284E` / 金赭 `#8D560E` / 蓝 `#1B5A94`），不表示发展程度；**无图表、无占比、无排名**。
  - **管理员不出现教师确认操作**：无“去处理待确认”，无全园待确认计数（管理员没有教学权限，可操作待办恒为 0，不把全园观察当作管理员任务）。
- **管理入口**：管理班级（进入班级列表与**班级页证据聚合**）；管理教师（教师账号与任教分配，属**计划实现的正式功能**，设计上正常展示，不标注“后续/待开发/占位”；实际可用性依赖后续 AUTH 管理 UI 接入，见 `handoff-r1.md`）。
- **禁止**：观察原文、教师名单、报表、复杂图表；班级证据聚合留在班级页面。

## 8. 状态矩阵（对齐 `HomeViewer` / `HomeNotice` / 错误语义）

| 状态 | 表现 | 要求 |
|---|---|---|
| 加载 | 骨架块占位，保持布局 | 不用纯 spinner 空屏；不先闪未登录再变教师态 |
| 凭证错误 | 内联“账号或密码不正确，请重试” | 不区分字段、不枚举账号；`invalid_credentials` 401 |
| 登录限流 | “尝试过于频繁，请稍后再试” | `rate_limited` 429，与凭证错误文案区分 |
| 账号停用 | “账号已停用，请联系管理员” | `account_disabled` 403；不伪装成登录错误 |
| 身份服务不可用 | 独立提示“身份服务暂时不可用，请稍后重试。”＋重试 | `identity_unavailable` 503，fail closed，不渲染任何园所数据 |
| 数据读取失败 | “班级与观察数据暂时读取失败，未展示任何数字，请稍后重试。”＋重试 | `data_unavailable`；计数为 `null`（未获取）≠ 0；已知待办仍可处理，依赖未知数量的分支显示 `retry` |
| 未分配班级 | “等待班级分配 / 请联系园所管理员安排任教班级。” | `scope_empty`；无创建班级捷径 |
| 已分配无幼儿 | 主行动“建立第一个成长档案” | `empty_children`，info 级提示，不是错误 |
| 无观察 | “还没有观察记录，从一次真实的观察开始。”＋开始记录 | `empty_observations`；0 是真实零值 |
| 长姓名 | 1–2 行自适应或省略号＋完整 title；行高稳定 | 示例“阿依努尔·麦麦提” |
| 多班级 | 学段分组；组内列表纵向展开 | 小班 2 个班同屏可见；长班名换行 |
| 指南关联待核对 | 不在首页出现 | 与观察三类待办分开，不与任何首页数字合并 |

**未知/错误不得伪装成普通空态；错误 ≠ 空数据；空范围 ≠ 全园。**

## 11. AUTH 契约对齐与实现边界

- 对齐来源：`cfa7b0343fc942ef80dc908ddfb47a96cb5a44dd`（AUTH0-R2）的 `docs/auth-v1/contract.md` 与 `src/lib/home-v2/types.ts`（只读）。
- 首页消费口径：`viewer` 四态（logged_out/teacher/admin/identity_unavailable）；`scope` 三形态（school/classes/none）；`class_groups` 按小→中→大；`pending_counts` 三计数分离，`null`=未获取、`0`=真实零；`primary_action` 固定优先级；`notices` 语义码；管理员 `pending` 为空、待办 0；历史只读记录不进待办与计数。
