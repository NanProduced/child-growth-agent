# 芽芽助手 UI1 Surface Brief（Operate 模式）

本文件是 UI1 表面的实现口径，依据 `PRODUCT.md` / `DESIGN.md`（“轻量成长观察册”）、
`docs/design/yaya-v1` 的 brief / message-spec / recovery-spec，以及 2026-10-06 用户批准素材。
不重新选择视觉方向，不重做首页/全站画风；`home-*` token 不进入助手表面。

## 1. 表面与模式

| 表面 | 路由/形态 | 模式 | 关键成功 |
|---|---|---|---|
| 入口按钮 | 全局右下浮动（`/assistant` 隐藏） | Operate | 一眼看到芽芽；状态用文字 + `aria-live` |
| 桌面侧栏 | `≥1024px` 非模态右侧栏 `clamp(360px,30vw,460px)` | Operate | 边看边聊：不推挤布局、无焦点陷阱、Escape 关闭并归还焦点 |
| 手机全屏 | `<1024px` 全屏会话页 + 安全区 + `100dvh` | Operate | 输入区随页面滚动；返回/关闭等效 |
| 工作区 | `/assistant`：会话列表 + 消息流 + 宽屏核对台 | Operate | 同一会话同一历史；批量核对只提交选中且完整项 |
| 消息与卡片 | 消息流内 | Operate/Read | 长答完整、Markdown 安全、六类结果分型、回执才成功 |

## 2. 与批准素材的对应

- **头像**：`yaya-avatar-transparent-v2.png` → `public/assets/yaya/yaya-avatar.png`（1254×1254 RGBA），
  只作 24–32px 识别与状态承载，不进入信息结构；姿态板与界面图**不切片、不贴图**。
- **A 桌面侧栏**：结构参考卡内草稿、核对折叠、对象/来源 chips、输入区；
  事实、状态、数量、按钮全部 HTML。
- **A 手机全屏**：结构参考头部（返回/历史/新对话）、批次条、卡内按钮、输入区；
  实际实现为响应式布局，不是 390×844 截图复刻（真实视口已验收，见交付文档）。
- **C 宽屏工作区**：核对台独立列，提案/待补充分开，只提交选中且完整的项。
- **状态反馈**：响应中/待核对/保存中/已保存/结果未知/受限使用文字 + 小指示点；
  `prefers-reduced-motion` 下动画停用，状态仍由文字表达。绿色勾只表示平台操作回执，不表示幼儿达标。

## 3. 颜色与形状（沿用全局 OKLCH 与现有语义）

- 草稿/待判断=天蓝；待补充=玫红；待确认=琥珀；已归档=绿；AI=紫；始终附文字标签。
- 不新增色板、不使用渐变文字/玻璃装饰/左侧色条；卡片 12px 圆角、1px 边框；
  阴影只用于侧栏/弹层；不使用厚重 SaaS 阴影。
- 嵌套子卡是 message-spec 的显式要求（多幼儿独立核对卡），不是默认卡片嵌套。

## 4. 交互与无障碍要点

- 核心触控目标 ≥44px（入口、发送/停止、返回/关闭、核对勾选行、选图）。
- 输入法：中文 IME 组合期间 Enter 不发送（`isComposing` 守门）。
- 桌面非模态：背景页面可交互；手机全屏是页面级导航；图片查看器是模态 Dialog（焦点捕获）。
- 长答默认收起并可展开全文；表格/列表/代码/引用按安全子集渲染，链接仅 http(s)。
- 只读态隐藏写按钮；受限内容显示原因文本，不显示空数据。

## 5. 视觉验收约束

- 批量检查一次（1440×900 / 768×1024 / 390×844），集中修复一次，确认最多一次；不无限 polish。
- 软键盘：本轮只做布局实现（`100dvh` + 安全区），真机软键盘 NOT_RUN，不以改 viewport 冒充。
- 证据与场景分层见 `docs/yaya-v1/ui1-delivery.md`。
