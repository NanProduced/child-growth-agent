## 2. 提取与核对方法

1. **主文本**：解析通知附件 `.doc`（OLE 复合文档，Word 97 文本片段表）得到正文与表格单元格全文。
2. **整格比对**：将 `.doc` 每个目标、每个年龄段的单元格与 CERNET 正式颁发稿同格文本规范化比对（忽略空白、全/半角标点差异与条目编号）。结论：**内容一致**；仅版式不同（CERNET 用 `·` 标出子项、部分建议编号为 `1.`，`.doc` 对应位置为自动编号或全角 `1．`）。
3. **分龄列核对**：2021 图文版 PDF 正文页含文本层。按表格三列的几何位置（列首 x 坐标由每页首行推定）逐列提取，未跨列拼接；再与 `.doc` 单元格逐条对齐（`scripts` 之外的本地核对脚本，见交付说明）。目标、子领域、年龄段归属与条目顺序以三份来源一致为准。
4. **条目编号**：`.doc` 中一部分表现条目使用 Word 自动编号，文本层不含编号；按 2021 印刷版逐格核对，确认每格条目为 1..n 连续编号后，统一写为 `N．`（全角句点），不改动条目文字。
5. **版式归一**（只处理排版噪声，不改语义）：
   - 合并 Word 软换行造成的句中断行（如“能双手抓杠悬空/吊起20秒左右”），使条目成为完整句子；
   - “身高和体重适宜。参考标准：……”条目保留原分行（男孩/女孩、身高/体重），`.doc` 5～6 岁格中“身高…厘米体重…公斤”原样保留；
   - 删除中文标点前多余空格、页眉页脚与分页符；
   - 教育建议按官方编号 `N．` 独立保存，子项保留 `·` 前缀与换行。

| 社会·人际交往·目标4·5～6岁·2 “能关注别人的情绪和需要，并能给予力所能及的帮助。” | `allowed` | “帮助”指儿童帮助他人，不是成人帮助条件，不触发独立性限制。 |
| 健康·生活习惯与生活能力·目标3·5～6岁·1 “未经大人允许不给陌生人开门。” | `allowed` | “大人允许”是行为规则条件，不是完成帮助；若确有成人代做，教师须在备注中说明且不应据此确认表现。 |
| 安全、保健类条目（如“不吃陌生人给的东西，不跟陌生人走”“在公共场所走失时能说出……简单信息”） | `allowed` | 成人无法代做；若使用了成人帮助，服务端仍要求说明帮助方式，教师据此判断能否确认表现。 |
| 健康·身心状况·目标1·1（三个年龄段）“身高和体重适宜。参考标准：……” | `health_reference` + `counts_in_behavior_stats=false` | 保健参考不进入行为比例，班级页不展示占比。 |

规则说明：

- `sustained` 只由原文的跨时间频率 / 比率 / 习惯表述触发；复合条目只要任一半句含此类表述，整条按 `sustained`（确认表现须覆盖完整描述）。
- `喜欢 / 愿意 / 乐于 / 感兴趣 / 敢于` 本身不构成 `sustained`；仅在原文同时出现频率、比率或习惯限定时才升级。
- `requires_independence` 表示“成人替代儿童完成目标动作时不能确认表现”，不禁止教师指导、示范与材料支持；`allowed` 条目若确用成人帮助，仍须教师说明帮助方式。

## 5. 目录真值保护（防污染）

- 三个查询接口的返回值统一使用标准 `structuredClone` 深拷贝；调用方修改返回的条目、`product_rules`、来源、目标定位链或教育建议，都不会影响后续查询与目录真值。
- 公开数据出口 `GUIDE_CATALOG`、`GUIDE_EDUCATION_SUGGESTIONS`（以及经由它们可达的各领域导出对象）在模块加载时递归 `Object.freeze`，直接 import 也无法改写。
- 未引入任何新依赖或通用不可变数据框架。
- 反例检查（`scripts/check-guide-catalog.ts` 第 10、11 项）：
  - 修改 `listGuideItems` 返回条目的 `text` / `product_rules` / `source.section` 并清空数组 → 再次查询返回原值；
  - 修改 `getGuideItem` 返回详情的 `item` / `goal` / `sub_domain` / `domain` / `education_suggestions` → 再次查询与建议接口返回原值；
  - 修改 `listEducationSuggestions` 返回值 → 再次查询返回原值；
  - `Object.isFrozen` 对目录根、领域、条目、`product_rules`、来源、建议及其元素均为 true。
