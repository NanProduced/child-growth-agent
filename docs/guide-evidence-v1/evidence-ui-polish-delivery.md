## 已处理的评审问题

- 实际按 `links[].basis[]` 读取来源，复用既有 Zod 链接 schema；核对响应幼儿、当前班级/学段、目录、期间、筛选与条目。不再使用不存在的 `bases`，也不把错误 JSON 当真实空值。
- 人数标尺由实际名单 N 生成，分布段按人数比例布局；0 人不产生占比。partial/unavailable 与真实无记录分开，保健参考仍不参与行为统计。
- 只允许一个选中条目与一个详情面板；Portal 将详情放入工作台独立区域，取消多个绝对定位面板重叠。窄屏切换为详情阅读，提供返回按钮和焦点恢复。
- 来源读取绑定账号投影、条目、幼儿、目录、范围以及本次服务端 item 对象；取消的请求不能写回新目标，旧请求没有独立 finally 去清除新请求的 loading。401 重新核验身份，损坏/范围变化刷新概览，其余读取失败可重试。
- 去掉生产组件里的固定“合成数据”标签；幼儿选择是原生按钮，支持键盘。成人帮助说明按条目规则区分，不一律降级为线索。
- 类型恢复先保留快照，再按字节恢复全部旧文件（含被构建删除的旧文件），不在恢复后再删除整个预览类型目录。

## 个人页

展开先读最近一条真实来源，其他记录、条目规则和关联审计按需展开；备注仅放在所属记录内，多来源关联的备注留在其关联详情，不能误归最新引用。来源日期、原始观察/确认稿、当时班级、教师备注、连续纪要、撤回理由均可查看。未知班级不回填，个人历史不按当前学段排除，待核对资料不冒充正式事实；管理员无教学写按钮。

文案使用“查看记录”“老师备注”“当时班级未记录”等教师能直接理解的说法，保留冻结的正式三态名称。Impeccable 影响了信息减量、字号、焦点、触控尺寸、异常状态与动态偏好处理；没有另建全站视觉系统。
