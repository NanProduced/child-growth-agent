## 三份方向（先看这里）

| # | 方向 | 消息密度 | 核对方式 | 移动端布局 |
|---|---|---|---|---|
| A | **册页卡** | 低：一主题一卡，卡片即正文 | **卡内核对**：核对区在卡片底部展开 | 单列卡流 + 底部吸附操作条 |
| B | **短句流** | 高：短气泡 + 紧凑动作行 | **逐步核对**：每个检查点一个小消息，编辑进底部抽屉 | 对话优先 + 底部抽屉编辑 |
| C | **核查台** | 中：左侧短对话 + 右侧核对栏 | **分栏核对**：右侧专用核对面板 | 「对话／核对」双标签页（带待核对角标） |

三份方向共用同一业务口径、同一权限模型、同一记录 ID 与同一正式守门；差异只在固定入口内的密度、核对位置与移动端组织方式。不重开首页或品牌竞赛。详见 `direction-options.md`。
