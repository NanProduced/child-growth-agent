# 未来真实浏览器验收规格（当前 NOT_RUN）

**状态：NOT_RUN。** 本目录没有任何助手/图片实现，未跑浏览器；本文是给未来 UI1/QA1 的验收规格。**当前不得标 PASS，也不得用合成图稿或本规格替代真实浏览器证据。**

## 1. 环境与前置

- 真实本地预览 + 真实登录会话（教师、管理员、未分配教师）；隔离库与合成数据，公开演示数据明确标注。
- 真实浏览器（桌面 + 移动视口模拟），`prefers-reduced-motion` 可切换；断网可模拟（DevTools offline）。
- **软键盘分层**：用 `visualViewport`/DevTools 模拟只能标记“模拟验收”；真实设备软键盘（iOS/Android 至少各一台）单独标记“真实设备验收”，两者不互相替代。 [R1]
- 图片链路需要真实上传/存储与真实 provider 或受控替身；替身结果单独报告，不冒充真实模型 PASS。
- 每轮记录：浏览器与版本、视口、账号、数据版本、网络条件、证据文件路径。

## 2. 视口矩阵

| 视口 | 布局预期 |
|---|---|
| 1440×900 | 右下角入口 + 右侧栏（`clamp(360,30vw,460)`）；工作区分栏（方向 C）或单列（A/B） |
| 768×1024 | 平板：入口可达；助手为覆盖式面板或工作区；无横向滚动 |
| 390×844 | 全屏会话；软键盘；安全区；返回/关闭；长卡片整页滚动 |

每个视口断言：

1. `document.scrollingElement.scrollWidth <= viewportWidth`（无横向溢出）；长文本与多卡下同样成立。
2. 所有可点目标 ≥44×44px（入口、发送、附件、缩略图、卡片按钮、关闭）。
3. 输入框聚焦且软键盘弹起时仍可见（390 视口用真实软键盘或 visualViewport 模拟）。
4. 安全区：`env(safe-area-inset-bottom)` 生效时输入区不被遮挡。
5. 页面主内容不被入口/面板永久遮挡（除面板打开期间）。

## 3. 键盘与焦点

- `Tab` 顺序可预测：入口 → 头部动作 → 消息区交互元素 → 输入 → 发送。
- 焦点可见（沿用现有 `:focus-visible` 语言，≥3px、4px 偏移）；不出现焦点丢失。
- **层语义（R1）**：桌面侧栏为非模态——背景页面仍可点击/滚动，焦点不被强制捕获，`Escape` 关闭并归还焦点；核对抽屉/确认对话框为模态——焦点陷阱、后台不可 Tab 到达、关闭归还触发元素。手机全屏为页面级导航（系统返回链）。
- 中文 IME：组合期间 `Enter` 不发送；组合结束后 `Enter` 发送。
- 长回答可展开/收起，键盘可达“展开全文/展开来源”。
- 状态变化通过 `aria-live="polite"` 宣布（响应中、回执、六类状态），不重复轰炸。

## 4. 减少动态

- 开启 `prefers-reduced-motion: reduce`：小芽姿态、淡入、滑入、滚动平滑全部停用。
- 停用后仍能区分：响应中/待确认/保存中/成功/异常（文字 + 静态徽章 + 姿态图形），**不得只剩颜色**。

## 5. 内容与错误态矩阵

| 类别 | 用例 | 期望 |
|---|---|---|
| 长文本 | 5000 字原文、长教育回答（多段+来源）、长姓名（如“阿依努尔·麦麦提”）、长班名 | 回答不裁断、可展开；布局不撑破；无横向滚动 |
| 问答 | 一般教育咨询、看图问答（不选幼儿）、范围内查询、管理员查询、未分配教师问答；同一段多人事实的“帮我分析”与“帮我分别记录” | 各自形态与边界正确；来源真实可点；无权限数据不出现；**分析不自动建记录卡，仅显式记录意图建卡** |
| 多卡 | 2–5 幼儿批次（混合：已保存/明确失败/冲突/结果未知/待补充） | 六类逐项状态；只重试“明确失败”项；已保存不可再提交 |
| 图片 | 上传中/上传失败/已上传未分析/分析失败/分析完成/移除；大图查看 | 逐图状态与重试；分析失败可继续文字；无假缩略图 |
| 等待 | 模型 60–120s 超时 | 可中止；中止不显示假成功；输入保留 |
| 权限/身份 | 未登录 / 管理员教学动作 / 未分配 / 撤权但有效（可问答）/ 账号停用 / 会话失效 / 身份 503 | 撤权可一般问答；停用/失效/503 全部模型调用关闭；对应说明与下一步；无数据泄露 |
| 空态 | 无历史、无幼儿、无指南条目 | 如实空态 + 下一步，不与错误混用 |
| 结果分型 | 断网保存、409、依据失效、已提交详情失败、原操作进行中、回执缺项、读取失败 | 六类分别呈现；未知只查原 operation_id；无自动重发、无新建提案绕过 |
| 成功归属 | 原操作成功但另一端/另一位教师写入不同内容 | 不显示“你的修改已保存”；明确他人更新；自己的内容走新核对/新批准 |
| 中间效果 | 上传成功、准备卡生成、审核通过 | 只描述本层；不显示“已确认归档” |
| 批准完整性 | 最后批准前 | 实际对象、关键事实、修改内容、附件关联均可展开核对；数量摘要不能替代 |
| 私人持久化 | 关闭聊天再打开、切换页面、跨设备同账号 | 准备内容/聊天按账号私有契约恢复；不自动形成业务观察；不撤销业务写入 |
| 恢复反例 | 原请求未结束读到未归档 / 另一端已写不同内容 / 另一端归档不同内容 / 审批后改字段 / 恢复旧批准 | 不判失败、不覆盖、不冒充自己的成功、旧批准失效、不自动执行 |
| 恢复 | 刷新、重开面板、换标签页、跨设备同账号 | 会话恢复；不自动重放写入；账号切换清私有投影 |

## 6. 跨设备与账号

- 同账号另一浏览器上下文恢复会话，历史可见；已完成的写入不回放、不重复。
- 切换到另一账号：上一账号的草稿、附件缩略图、待提交选择立即消失；不闪现旧数据。
- 撤权后（转班/移除任教/停用）：历史中的受限内容显示受限投影，不渲染旧详情；一般问答按角色能力。

## 7. 证据要求（每项断言）

- 截图（含视口标注）或录屏；DOM 度量（scrollWidth、目标尺寸、焦点元素）；控制台无未处理异常；网络面板证明写请求次数（尤其“只发一次”“不自动重发”）。
- 图片、长文本、多卡、错误态分别留独立证据，不用一张“全绿截图”代替。
- 结果分级报告：本地闭环 / 组件级 / 真实模型 / 托管库与部署，**分别报告，不互相替代**。 [C] 需求 §7
