# 合成示例：两个幼儿、一张共同照片、一条真实缺口追问 — R2

> **来源声明（必须随稿展示）**：合成的是**幼儿、事件与照片**；园所“星芽幼儿园”、班级“向日葵班（中班）”、幼儿“小满”“阿依”均为**化名**，照片为**合成示意图**（不出现真实幼儿面孔），日期与事件为设计构造，**不是真实园所数据，也不是教师实测**。
>
> **指南事实不是合成的**：条目原文、年龄段与产品规则取自当前仓库目录 `src/lib/guide/catalog.ts`（数据在 `src/data/guide/*.ts`），逐字引用；引用方式为 `id + 全文`。`product_rules`（证据类型/是否计入行为统计/成人帮助策略）是**本产品的关联口径**，不是官方统一测评标准，也不代表儿童达成水平。

## 2. 两种意图，两种结果（R2 对照）

同一段多人事实，入口意图不同，结果不同：

| 教师说法 | 意图 | 结果 |
|---|---|---|
| “帮我分析一下这两个孩子刚才的表现” | 分析/咨询 | 直接回答 + 可选 `准备为观察` / `分别准备为观察`；**不自动建卡** |
| “帮我分别记录小满和阿依的观察” | 显式记录 | 生成两张独立记录卡（下方 §3），各自核对、各自保存 |

只提到“小满和阿依”不构成记录意图；歧义（重名/指代/映射不明）才澄清。 [R2]

## 3. 两张独立卡（同一事件，不同事实与帮助条件）

| 项目 | 小满卡 | 阿依卡 |

| 帮助条件 | **未使用成人帮助** | **使用了成人帮助**（有提醒；方式/内容未知） |
| 条目证据类型 | 行为表现（单次充分证据即可） | 行为表现（单次充分证据即可） |
| 成人帮助策略 | `allowed` | `allowed` |
| 规则应用 | 独立完成，无障碍 | **帮助本身不等于降级**：条目允许成人帮助；但确认表现需按现有业务检查说明帮助方式 [C] `decision-draft.ts:123-124` |
| 可能决定（教师核对后） | `已确认观察到` | 若教师能补充帮助方式且证据充分 → 可 `已确认观察到`；若记不清/跳过或判断证据不足 → 可 `已有相关线索` 或暂不关联。示例不承诺任何必然结果 |

- 两张卡分别核对、分别保存；**不把“小满的做法”复制进阿依的事实**。

## 4. 一条待补充卡（阿依 · 第 1/2 轮，真实缺口）

> 芽芽：你当时是怎样提醒阿依的？方式或大致内容都可以，不用逐字回忆；记不清也可以跳过。
> 为什么需要：本次涉及成人帮助；帮助方式会影响关联记录与后续支持建议（逐字原话不是必填）。
> 教师补充：略（可跳过）
> `[回答并继续] [跳过，直接整理] [不再追问]`

- **这是真实缺口**：原文只写“我提醒了她一下”，没有写提醒方式和内容；追问不重复任何已给出的信息（搭桥过程、塌三次、换底座、她过去问、小满教了一块、一起搭了一段，均已知，不再问）。
- **不强迫回忆逐字原话**：教师可以只写“就是提醒她可以问问别人”这类大致描述，也可以跳过。
- 小满卡不受这条追问影响：可先核对、先保存。
- **跳过/记不清的处理（R2）**：仍可保留事实并整理、确认这条观察；**有疑问的指南关联暂不确认**——可先按 `已有相关线索` 或暂不关联，等有依据再补；不阻塞其他幼儿。产品规则不因成人帮助自动降级，也不因缺少帮助描述自动确认；是否确认表现由教师按现有业务检查决定。 [C] `decision-draft.ts:123-128`

## 5. 批次与逐项结果（合成）

```
本批 2 条 · 已保存 1 · 待补充 1
☑ 小满卡（已核对 · 独立完成）
   → 已确认归档 · 14:32 · 观察 #a1c1…；成长档案已更新；指南关联已写入（已确认观察到）
☐ 阿依卡（待补充：提醒方式/内容未知，可跳过）
   → [补一句]  （不阻塞小满）
```

- 若保存小满卡时网络中断：小满卡进入 `结果未知，按原操作核对`（不是“失败”，也不自动重发、不新建提案）；阿依卡与已核对选择仍在。 [C] `recovery-spec.md` §1.3
- 若另一端先把这条记录归档成了不同内容：说明“该记录已由另一操作归档，你的未提交内容仍保留”，**不显示“你的修改已保存”**；原记录只读，不再次归档，不自动复制新观察。
- 若阿依卡保存时发现条目依据的观察版本已变化：该卡进入 `前提已变化，需要重新核对`；小满卡回执不受影响。 [C] `recovery-spec.md` §1.2
- 批次分型不把“待补充/冲突/结果未知”混称“待核对”，也不整批重发。 [R1]

- 成长档案时间线显示：小满 2026-10-08（已确认归档，科学，含共同照片引用 + 长桥特写）；阿依同日（待补充/随后按教师决定确认或保留线索）。
