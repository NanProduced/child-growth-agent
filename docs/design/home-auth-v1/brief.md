- 分支：`codex/home0-auth-design`（独立工作树，基线 `b02e4a1`）
- 范围：**只设计，不实现**。未修改 PRODUCT / DESIGN / 全局 CSS / 首页组件 / top-nav / teacher-provider / auth / API。
- 设计稿状态：**NOT_RUN**。本环境没有可用的内置 ImageGen 工具，按任务约定交付精确图像 prompt（`prompts/`），未使用 API 密钥或 CLI 替代，未用 CSS/emoji 冒充插画。
- 视觉对照（需改进）：`codex-clipboard-42357a39-db68-473f-b747-bb9735d78974.png`。只作问题样本：人物被卡片覆盖、场景细节过多、业务位置绑定画面。不要求原样复制，也不作为生成输入的构图依据。

## 1. 方向（保留 / 取消 / 新结构）

**保留**：芽芽观察、暖白画布、芽叶绿主行动、轻绘本气质、少量卡通、证据导向的信息层级。

**取消**：

- 全屏复杂地图与密集背景场景；
- 漂浮纸牌、压在人物身上的业务面板；
- 业务内容与插画固定坐标绑定的布局；
- 深色 SaaS 侧栏、大量 KPI、雷达图、排名、个人百分比。

**新结构**：

- 插画独立完整占位：自成一栏或一条独立横幅，画内无文字、无按钮、无数据，不被任何卡片遮挡；
- 业务内容采用自然流排布，数据增长只向下生长，不改变既定构图；
- 登录组件与插画互不遮挡；
- 文字与控件未来一律 HTML 实现，图片只负责视觉，不能作为业务交互面板。

**文案（本轮确定）**：

- 主文案：**以三年为序，看见幼儿持续生长**
- 辅助：**从小班到大班，连接观察证据与教育支持。**
- 不出现“待开发”“演示数据说明”“合成数据”“演示园所”等文案；界面使用合成示例，不写真实密码或儿童私人资料。

## 2. 三态目标与主行动

| 状态 | 访客目标 | 唯一主行动 | 数据边界 |
|---|---|---|---|
| 未登录 | 理解产品定位并登录 | 登录（账号 + 密码） | 不展示儿童数据、全园班级人数、观察内容；不提供管理员/教师任意切换，角色由账号决定 |
| 教师 | 完成一次核对或记录 | 有待确认：**去处理待确认**；否则：**开始记录**（沿用确认优先） | 只显示本人负责范围；少量待核对与最近观察摘要 |
| 管理员 | 进入管理动作 | **管理班级**（可进入班级聚合） | 全园学段/班级聚合；不铺教师名单、观察原文和报表 |

## 4. 未登录态（桌面）

- **定位区**：小标签（面向幼儿园教师的成长观察与活动支持智能体）+ 主文案 + 辅助语。主文案可两行，不占满首屏。
- **登录面板**：账号、密码、登录按钮、帮助语“账号由园所管理员分配，角色由账号决定”。错误提示有预留位置（不推挤布局）。不提供注册、不提供身份切换。
- **插画**：位于定位区右侧的独立列，完整显示，尺寸约 480–520px 宽；不与登录面板重叠。
- **机制三步**：记录原始观察 → AI 整理草稿 → 教师确认归档。弱化处理，一行三组，小图标，不卡片化；第三步明确“确认归档”由教师完成。
- **禁止**：儿童姓名、班级人数、观察摘要、任何数字统计；任何管理入口。

## 5. 教师态（桌面）

- **身份**：真实姓名 + 身份说明（如“小班教师”）+ 负责范围（学段与班级数、学年）。姓名区允许 1–2 行，长姓名规则见状态矩阵。
- **网络写实规则**：教师身份与负责范围来自账号与班级归属数据；当前代码没有教师账号和班级归属表，这是设计前向，实施依赖后续账号模型（见 §11）。
- **唯一主行动**：有待确认观察时，主行动为“去处理待确认”（确认琥珀 `#BF6805` 按钮 + 条数）；否则为“开始记录”（芽叶绿 `#008344`）。两者不同时以主按钮出现。
- **我的班级**：按学段分组（**学段是分组，不是班级**）；组内允许多个班级。**必须出现同一教师负责两个小班的情况**（示例：小班组下“芽芽班”“苗苗班”）。每行：班级名、在班人数、待确认数、进入箭头；行是 HTML 控件。
- **摘要**：待核对 2–3 条（日期、幼儿姓名、一行摘要、状态词），最近观察 2–3 条。状态只用既有流程词：待确认 / 待补充信息 / 已保存 · 待判断 / 已确认归档；不用叶片替代关键状态。
- **未分配班级**：替换“我的班级”区域为说明面板：“尚未分配班级 / 请联系园所管理员为你的账号分配班级。”**不提供“自行创建班级”捷径**。
- **禁止**：全园教师名单、其他班级细节、数量堆叠、雷达/百分比/排名。

## 6. 管理员态（桌面）

- **身份**：管理身份与全园范围一句话（园所名 · 学段数 · 班级数）。
- **全园概览**：三个学段块（小班/中班/大班），每块显示班级数、成长档案数、待核对条数。学段色仅作识别（珊瑚 `#A7284E` / 金赭 `#8D560E` / 蓝 `#1B5A94`），不表示发展程度。不用雷达、占比、排名；不做数据驾驶舱。
- **管理入口**：“管理班级”为主入口，可进入班级聚合；“管理教师”为后续入口（当前无教师实体，实施待后端，设计保留入口形态）。
- **班级聚合**：从学段块或管理班级进入，聚合视图不在首页平铺。
- **不复用教师确认主按钮**：管理员页面不出现“去处理待确认”；班级行内是“查看班级聚合”类入口。
- **禁止**：全部教师名单、观察原文、报表平铺到首页。

## 7. 窄屏规则

**教师 390（出稿）**：单列自然流。顺序：身份 → 插画横幅（独立、完整，高约 150–190px，不裁剪人物）→ 主行动（56px 胶囊，全宽）→ 我的班级（学段分组，班级行整行可点）→ 待核对 → 最近观察。触控目标 ≥44px；不横向滚动；长姓名/长班名换行规则见 §8。

**未登录 390（写入 brief，不出稿）**：单列。顺序：定位文案（标题 + 辅助语）→ 登录面板 → 插画横幅（完整，不裁人物）→ 机制三步纵向排列。登录按钮全宽 56px；键盘聚焦可见（3px 深绿轮廓、4px 偏移）。

**管理员 390（写入 brief，不出稿）**：单列。顺序：管理身份 → 全园概览（三个学段块纵向排列，数字不缩写）→ 管理入口列表。不用表格、不横向滚动；“管理班级”为全宽主入口，“管理教师”为次级入口。

**共同**：顶栏在 1024px 以下重排为两行，保留文字与图标；状态不只用颜色表达；桌面态在数据增长时向下生长、不重排首屏。

## 8. 状态处理矩阵

| 状态 | 表现 | 要求 |
|---|---|---|
| 加载（身份检查/数据） | 骨架块占位，保持布局 | 不用纯 spinner 空屏；不先闪出未登录表单再变教师态 |
| 登录错误（凭证错） | 字段下方内联错误：“账号或密码不正确，请重试” | 不区分哪个字段错、不枚举账号；错误位预留，不推挤布局 |
| 登录错误（网络/服务异常） | “暂时无法登录，请稍后重试” + 重试 | 与凭证错误文案区分 |
| 身份服务不可用 | 独立提示带：“身份服务暂时不可用，请稍后重试。” + 重试按钮 | 不伪装成未登录、不显示 0 数据空态；未知/错误不得画成普通空态 |
| 账号未配置园所权限 | “该账号暂未配置园所权限，请联系管理员” | 不进入教师/管理员任一侧 |
| 未分配班级（教师） | “尚未分配班级” + 联系管理员说明 | 无“自行创建班级”捷径 |
| 无观察（教师） | 平静空态：“还没有观察记录” + 开始记录（主行动） | 0 是真实数字；不用错误样式、不催促 |
| 长姓名 | 姓名 1–2 行自适应或省略号 + 完整 title；身份行高度稳定 | 测试串示例：阿依努尔·麦麦提 |
| 长班名/多班级 | 班名换行，班级行高度自适应；学段组内列表纵向展开/滚动 | 示例：彩虹糖国际双语实验班 |
| 统计/数据不可靠 | 保留原文与人数分母，明确“暂不可用” | 技术异常不是第四种儿童状态（承袭 DESIGN.md） |

## 10. 中文字体子集风险（已实测）

现有展示字体子集 `public/assets/fonts/yaya-display-subset.ttf`（MaShanZheng，OFL）共映射 31 个码位：

```
一个中今儿全园在大天察小幼成最案档正每班生的看眼芽要见观近长
```

- **已覆盖**：旧主标题“看见每一个正在生长的幼儿”、学段名（小班/中班/大班）、全园、今天要看一眼、最近观察。
- **新主文案缺失 8 字**：`以 三 年 为 序 ， 持 续`（码位 0x4EE5、0x4E09、0x5E74、0x4E3A、0x5E8F、0xFF0C、0x6301、0x7EED）。
- **辅助语缺失 13 字**：`从 到 ， 连 接 证 据 与 教 育 支 持 。`
- **风险**：新主文案若沿用毛笔展示字，缺失字会回落到 serif，出现混排字形断裂；`待确认/待核对/我的班级/管理员` 不在子集中，只能使用中文无衬线正文栈。
- **处理选项（实施时决定，本轮不执行）**：① 重新生成子集，补入上列码位（保留 OFL 与字重，更新字节数与 DESIGN.md 记录）；② 主文案改用无衬线正文栈，展示字只用于已覆盖的短词。**不未经授权替换全站字体。**

## 11. 实现边界（本轮不实现，仅记录）
