## 落地口径

- 桌面 >=1024：主页面与 360–480px 助手并排，非模态，主页面可导航、滚动；不叠放悬浮入口。小于1024：助手全屏，使用 Radix 模态焦点与视觉视口。
- 自然语言是主入口，不要求先选幼儿/来源/模块。模型沿用真实白名单工具与权限；写入仍由教师核对批准。
- 引用当前页或选中文字是可选关注线索，使用 assistant-ui 原生 quote，不改教师原文，不覆盖用户明确意图、不授权执行。
- 引用在手动添加时固定。切页不自动改写引用或既有提案；可查看、移除。主体内容、目标、日期、后果与回执完整可核对。
- 具体幼儿/班级/观察页面的选中文字附真实资源来源并逐步重核。列表页当前仅支持入口和筛选提示，不接受无逐项权限依赖的多幼儿选中文字；直接自然语言查询不受此限制。
- 使用已有 assistant-ui、Radix/shadcn、Lucide 和芽芽头像；无新依赖、状态库或图片占位。暖白/绿沿用项目 ground；所有文字与卡片均为真实 HTML，不把设计图裁成界面。
