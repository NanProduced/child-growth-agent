## 4. HOME1 接入说明（后续，不在本轮）

- **依赖顺序**：AUTH1（scrypt、会话、CSRF、限流、建表/迁移）→ 首页 v2 数据装配（消费 `src/lib/home-v2/types.ts`）→ AUTH 管理 UI（教师列表/创建/启停、任教分配、密码重置）→ “管理教师”入口真正可用。
- **DTO 映射**：`viewer` 四态；`scope` 三形态；`class_groups` 小→中→大；`pending_counts` 三计数且 `null≠0`；`primary_action` 固定优先级；`notices` 六类语义；管理员 `pending` 空、待办 0；历史只读不进待办。
- **登录面板**：本设计为首页内嵌“园所账号登录”面板；契约 `primary_action(login).href=/login`。实现轮决定内嵌面板与 `/login` 页的关系（锚点或独立页），不得引入角色选择器。
- **字体**：固定主标题需扩子集 8 字（以、三、年、为、序、，、持、续）；未获批时标题改无衬线；本轮不改字体文件。
- **素材**：主插画新生成或过渡复用 `homepage-classroom.png`（来源 sidecar 缺失，须先补齐，不得伪造）。
- **文件归属**：本设计只占 `docs/design/home-auth-v1/**`；首页实现归 HOME 实现方，认证归 AUTH 实现方；共享类型只能由契约负责人修订。
