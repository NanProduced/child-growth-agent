## 业务底线

- 三个正式状态为“已确认观察到 / 已有相关线索 / 暂无相关记录”，对应具体指南表现条目，不是幼儿能力、目标达成率或领域评分。
- 数据可靠时才显示完整三类分布；待核验条目只展示可确认人数下限，不把余数当“暂无相关记录”，不显示伪0或完整百分比分布。
- 保健参考资料单列，仅供查阅，不参与行为统计或正常/异常诊断。
- 当前在班名单与期间口径保留；方法说明只集中展示一次。所有图中20人及逐项8/5/7、6/4/10、9/3/8是合成设计数据，不能直接变成正式页面常量。
- 第四条“情绪比较稳定”示例为partial：至少2人确认、至少3人线索，其他情况未知。条目之间人数不可相加作为班级去重总数。
- 指南原文以src/data/guide/health.ts为准；简短标题只用于总览，原文与条件必须可查。原始观察不可改写，AI产出仍须教师确认。
- 原统计读取失败、权限变化、可靠空数据、未确认记录与无指南关联仍须区分。图稿不是这些状态已实现的证明。
